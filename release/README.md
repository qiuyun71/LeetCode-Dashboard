# 免安装版（Windows）

下载 `力扣刷题看板.exe`，**双击即可运行，目标机器不需要安装 Python**。

## 用法

1. 双击 `力扣刷题看板.exe`
2. 浏览器自动打开 <http://127.0.0.1:8765>
3. 关掉 exe 进程即停止服务（无窗口，右键任务栏图标结束）

首次运行会在 exe 同目录自动生成 `plan.json`（从内置模板初始化，100 道 LeetCode 题）。

## 数据存在哪

**就放在 exe 同目录的 `plan.json`**，每次操作立即写盘。

| 文件 | 作用 | 能不能删 |
|------|------|---------|
| `力扣刷题看板.exe` | 程序本体 | ❌ |
| `plan.json` | **你的刷题进度** | ⚠️ 删了进度就没了，记得备份 |
| `board.log` | 运行日志（排查问题用） | ✅ |

**换电脑 / 备份**：把 `力扣刷题看板.exe` 和 `plan.json` 两个文件一起拷走即可。

也可用页面里的「数据管理 → 导出 JSON」手动备份。

## 常见问题

**双击没反应？**
看同目录的 `board.log`。多半是端口 8765 被别的程序占了——
本工具同时只能跑一个实例，关掉另一个再双击。

**杀毒软件报警？**
PyInstaller 打包的 exe 常被误报，加信任即可。源码在仓库根目录，
想避开误报就用 `python server.py` 跑。

**改了界面但 exe 没变化？**
exe 里是打包时的快照。改完源码要重新打包，命令见 [`../build_exe.md`](../build_exe.md)。

## 体积说明

50MB 里大部分是 Python 运行时（PyInstaller onefile 模式）。
好处是零依赖，代价是体积大、启动时解压约 2 秒。
