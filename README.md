# 力扣刷题看板 ✧

> 一个 **Web Coding** 练手项目 —— 纯 HTML / CSS / JavaScript 前端 + Python 标准库本地服务，
> **运行时零第三方依赖**，双击 bat 就能跑。开发过程由 AI Agent（WorkBuddy）协作完成。

![screenshot](docs/screenshot.png)

每天打开看一眼：**今天该做哪几道**、做完打勾、没做完的题留在今天，日历记录你的坚持。

## ✨ 特性

| | |
|---|---|
| 📅 **动态计划** | 总题数 / 每天题数随手改，天数与结束日期自动重算 |
| ✅ **勾选即记录** | 当天题板打勾提交，没勾的题留在今天，随时「一鼓作气」补完；0 勾选也能「确认翻篇」让这天结束 |
| 🎊 **结算页** | 提交后弹窗展示：做完了哪几道、难度分布、还剩几题、累计进度；全部完成还有庆祝横幅 + 「挑战自我」 |

| 📉 **欠账上限** | 顺延到第二天，连同第二天自己的题合计最多「每天题数 × 2」道，超出的进「原计划最后一天」之后的**补做日**（总天数 +1，日历上琥珀色标注） |
| 🚀 **提前日标注** | 原定后几天的题被提前做掉，日历把那几天标薄荷青 + `↑`，且**总天数随之缩短**，附带「提前日达人」成就 |
| 🏆 **成就殿堂** | 右上角奖杯入口：19 个成就分 5 类（里程碑 / 坚持 / 爆发 / 收藏 / 计划），彩色卡片 + 进度条，点开看详情 |
| 🔄 **换题零副作用** | 换一道只是换一道，总量 / 天数 / 每日量全都不变 |
| 🎯 **自定义今天的题** | 题板上「✎ 自定义」从本题单没做过的题里自己挑今天做哪几道（带搜索），也可一键恢复系统出题 |
| 🚩 **标记「之前做过」** | 计入已完成、但不算每日做题量，且**计划天数会跟着缩短** |
| ⏸ **暂停 / 继续** | 记录一条不丢，暂停期间日历标斜纹灰、不算空缺 |
| 🔁 **无限轮次** | 刷完一轮可以「重新开始」，往期记录归档留档 |
| 📖 **多题单** | 自带 LeetCode 100，也可粘贴力扣题单链接自动导入 |
| ⭐ **错题本** | 任意题一键标记「经典 / 错题」+ 写备注，自动统计难度与考点分布 |
| ↩️ **撤销 30 步** | 几乎每个操作都能 `Ctrl+Z` 退回 |
| 🎨 **氛围感** | 水墨风竹林背景 + 雾气漂移 + 细雨 + 竹叶飘落，AI 生成的插画 |
| 📊 **统计与热力日历** | 连续天数、近 7 日均量、难度分布、单日完成最多纪录、悬停看当天做了哪几题 |

## 🚀 快速开始

**要求：Python 3.8+**（[官网下载](https://www.python.org/downloads/)，安装时勾选 *Add to PATH*）。
**不需要** `pip install` 任何东西 —— 本项目只用 Python 标准库。

### 方式一：Windows 双击（最省事）

下载解压后，双击 **`启动/打开看板.bat`**，浏览器会自动打开。

`打开看板.bat` 会按顺序找 Python：`python` → `python3` → `py -3` →
`%LOCALAPPDATA%\Programs\Python\Python3xx\` → 项目内 `python\`。
所以**装 Python 时没勾 *Add to PATH* 也能跑**（只要装在标准位置）。

### 方式二：命令行（macOS / Linux / 任何平台）

```bash
git clone <你的仓库地址> && cd leetcode-board

python3 启动/start.py   # 起服务 + 自动开浏览器
# 或者
./启动/start.sh         # 同上（macOS / Linux）
```

### 方式三：手动起服务（推荐给开发者）

```bash
python3 server.py       # 只起服务，浏览器访问 http://127.0.0.1:8765
```

| 命令 | 作用 |
|------|------|
| `python3 server.py` | 只起本地服务（前台，日志打在终端） |
| `python3 启动/start.py` | 检测端口 → 未运行则静默拉起服务 → 开浏览器 |
| `python3 seed_lc100.py` | 重建 LeetCode 100 题单（**会清空进度**，谨慎） |

> 回归测试脚本在开发副本里（`_x.py`，跑在独立端口的副本数据上，不碰真实 `plan.json`），
> 日常使用目录不带它。

### 环境变量（进阶）

| 变量 | 说明 | 默认 |
|------|------|------|
| `LEET_PORT` | 服务端口 | `8765` |
| `LEET_PLAN` | 数据文件路径 | `./plan.json` |

```bash
# 在副本上跑，不动真实数据（测试就是这么做的）
LEET_PLAN=_t_plan.json LEET_PORT=8799 python3 server.py
```

## 🖥 前台 / 后台运行

| 方式 | 命令 | 表现 | 怎么停 |
|------|------|------|--------|
| **前台**（调试用） | `python3 server.py` | 终端占着，日志直接打屏 | `Ctrl+C` |
| **后台 + 开浏览器**（日常推荐） | `python3 启动/start.py` | 立刻返回控制台，不留窗口 | 任务管理器结束 `python` / `pythonw` |
| **后台无窗口** | `pythonw server.py` | Windows 上完全没有黑框 | 任务管理器 |
| **后台 + 日志**（mac/Linux） | `nohup python3 server.py > server.log 2>&1 &` | 无窗口，日志落盘 | `pkill -f server.py` |

> `start.py` 用 `CREATE_NO_WINDOW | DETACHED_PROCESS` 创建子进程，
> 服务彻底脱离控制台；它还会先探测 8765 端口，已经在跑就直接开浏览器不重复起。
>
> 想彻底当后台服务（开机自启、崩溃自动拉起），可以再套一层系统服务：
> Windows 用任务计划程序 / NSSM，macOS 用 launchd，Linux 用 systemd —— 但对这个
> 一次性小工具来说没必要，`start.py` 足够了。

## 💾 数据说明

**所有数据都在 `plan.json` 这一个文件里**，纯本地、不联网、不上传。

仓库里放的是 `plan.example.json`（模板，内含 LeetCode 100 全部题目）。首次启动时若没有 `plan.json`，
服务会自动用默认题库生成一份。想备份进度，复制 `plan.json` 即可。

```bash
cp plan.example.json plan.json     # 手动初始化
```

`plan.json` 已在 `.gitignore` 里 —— **不要把自己的刷题进度传到公开仓库**。

### 关键字段

| 字段 | 含义 |
|------|------|
| `perDay` | 每天几题 |
| `limit` | 总题数上限（`null` = 全部） |
| `categories` | 题库：`[{name:"哈希", problems:[{id,name,difficulty,hint}]}]` |
| `done` | 完成记录 `{id, date}`；带 `pre:true` 是「之前做过」 |
| `board` | 已展开的天，含当天题目与勾选状态 |
| `rounds` | 往期归档轮次（重新开始一轮时留档） |
| `pauses` | 暂停区间 `[{from,to}]` |
| `marks` | 错题本：`{"题号": {"kind":"classic"\|"wrong", "at":"日期", "note":"备注"}}` |

**days 不落盘**：每天的题目是运行时由 `categories` 按 `perDay` 展平切分出来的，
所以改计划立即生效，也不会和已完成记录打架。

## 📖 功能说明

### 首次打开：欢迎页
第一次打开会弹出引导，两步走：设定计划（总题数 + 每天题数，天数自动算，实时显示强度提示）
+ 四张卡片讲清楚「勾选 / 换题 / 左侧面板 / 撤销」。也可以点「稍后再设」，
随时点主区顶部 **「⚙ 修改计划」** 再改。

### 当天题板
- 标题栏显示「第 N / M 天」，每题行尾两个按钮：
  - **⇄ 换一道**：纯换题，零副作用；被换下来的题回到本题单候选池
  - **⚑ 之前做过**：计入已完成、不计入每日量、计划天数随之缩短
- **换题 / 加题只从本题单里出题**：就是「本题单还没上板的那 N 道」，
  不去全局题池或其它题单借题，题目排完就是真没了
- **✎ 自定义今天的题**：不想按系统排的顺序做？点题板头部「✎ 自定义」弹出
  选题面板——本题单**还没做过**的题都能挑（已勾选的题会保留、每天最多
  N 道），带搜索框；面板里「↺ 恢复系统出题」一键回到当天的原始题目
- **确定完成**：勾选的记入记录，**没勾的题留在今天**（见下方「欠账机制」）
  - **0 题也能确认翻篇**：今天一道没勾，确认后这天直接结束——没勾的题按欠账
    规则顺延 / 进补做日，日历上这天记为未完成。适合「今天就是没刷，别让题板
    卡在这一天」
  -提交后弹**结算页**：这次做完了哪几道、难度分布、还剩几题、累计进度
  -**当天全部完成**：统计最上方多一条庆祝横幅（第几天 / 当天完成数 / 连续刷题天数，
    配撒纸屑），主按钮变成 **⚔ 挑战自我** —— 关掉弹窗给当天加一道题接着做。
    想多做题只能走「+ 加一题」，不会翻出第二天的卡
  -**没做完**：剩下的题还留在当天的题板上，主按钮是
    **「还差 N 题 · 一鼓作气 💪」**，点击关弹窗回到当天题板接着做；
    半途交过的次数也会累计，补完再交照样按当天总量庆祝
- **题板永远只显示当天**：提交后停留当天，绝不提前翻出第二天的卡片；
  翻篇只发生在零点自动结算、0 题确认翻篇或下次启动服务（见下方「每天自动结算」）
- 卡片底部只有 **↶ 撤销**（展开下一天交给服务端跨天自动做）
- 悬停「确定完成」按钮的问号，可以看到规则的完整说明

### 每天自动结算
不用每天手动点「确定完成」：服务启动时、以及运行中跨天时，会自动把日期落在
昨天及以前的题板天提交掉——勾选的题记完成（记在那天的计划日期），没勾的按
欠账规则顺延，然后自动展开到今天的题板。服务没开机也没关系，结算是按日期
驱动的，下次打开会一次性补齐（停了几天就补几天，没做题的天日历照常标红）。
暂停期间不自动结算；整个自动结算算一个撤销点，Ctrl+Z 可整体撤销。
**这也是切换到第二天的入口之一**：题板平时锁死在当天，跨天结算后才翻篇；
另一种主动翻篇是「0 题确认翻篇」（见「当天题板」）。

### 欠账机制（重点）
当天没做完的题**默认留在当天**：随时点「确定完成」都行，剩下的题还在板面上，
「一鼓作气」回去勾掉再交即可，不欠账、不挪窝。只有当天真正结束——**午夜自动
结算**、**0 题确认翻篇**、或**下次启动服务时的补结算**——时没勾的题才顺延：

- 顺延到第二天：**第二天连自己的题带顺延进来的，合计最多「每天题数 × 2」道**，
  超出的部分不再往后堆，而是**顺延到「原计划最后一天」之后新增的「补做日」**
  - 例：计划 25 天、每天 4 题。第 1 天 0 做 → 第 2 天 4+4=8 题；第 2 天仍 0 做
    → 第 3 天最多接 8 道（自身 4 + 顺延 4），多出的 4 道放到第 26 天的补做日——
    **进度条的分母从 25 变 26**，结束日期自动后移
  - 补做日 = 计划外多出来的一天，题板上是琥珀色「补做日」卡片，
    日历上对应日期也是琥珀色（区别于绿=做过、红=空缺）
  - 补做日永远排在原计划最后一天之后，「展开下一天」不会跳过计划内的天
  - 已有的补做日没做完就优先接着装，不会无限多开天

### 提前日（重点）
反过来，今天把原定后几天的题提前做掉了，那几天就是「提前日」：

- 判定：截至某一天的前一天，累计完成量已经够到那天的原定配额，那天就是提前日
  （当天自己做超的不算；过去被提前做掉、日历上已经翻篇的日子也算）
- 日历上提前日标**薄荷青 + `↑`**，悬停能看提前做掉了多少题；
  当天没题量的「纯提前日」也标色（原定那天的题已经提前做掉了）
- **进度条分母跟着缩短**：还是 25 天、4 题/天的计划，今天一口气做掉 20 题
  （5 天量）→ 提前 4 天，分母从 25 变 21，结束日期自动提前
- **补做日和提前日的界限以「原计划的最后一天」为基准**：晚于它的全算补做日，
  早于它的全算提前日

### 错题本 / 经典题
题板上每道题行尾有个 **☆** 按钮，点一下可以：

- 标成 **经典**（值得回看的好题）—— 琥珀色实心星
- 标成 **错题**（做错想再练）—— 粉色实心心
- 或者取消标记

侧栏「更多 → 错题本」里能看到全部标记过的题，包含：

- 统计卡：标记总数 / 错题数 / 经典数 / 已经做出来多少道
- 难度分布 + 高频考点（错得最多的前几个分类）
- 按「全部 / 错题 / 经典」筛选
- 每条可写一句备注（卡在哪、下次注意什么），失焦即保存
- 显示是否已经做出来过

标记存在 `plan.json` 的 `marks` 字段，跟着题单走，导出会一起带上。

### 成就殿堂
主界面**右上角一个奖杯图标**（徽标显示「已解锁 / 总数」），点一下弹出成就面板：

- 顶部三张大数字卡：已解锁成就、累计完成题数、连续刷题天数
- 19 个成就分 5 类，可按分类筛选：**里程碑**（累计题数）、**坚持**（连续天数）、
  **爆发**（单日做题量）、**收藏**（经典 / 错题标记）、**计划**（提前日 / 补做日 / 新一轮）
- 每张卡片：分类渐变图标 + 名称 + 说明 + 底部进度条（`当前 / 目标`），
  解锁的右上角带 ✓、图标恢复彩色；没解锁的是灰图标
- 记录型成就「**单日之巅**」（爆发类）：统计**所有计划**里单日完成题数最多的一天，
  卡片和详情直接摆纪录——哪天、几题、来自哪个题单（含历史轮次归档）；
  并列取更早的日期。任何计划完成过 1 题即解锁
- 再点卡片进**成就详情**：大图标、获取条件、进度百分比、还差多少，
  「提前日达人 / 清完补做」两个还带「去日历看看」跳转

进度全部由实时数据算出（做到哪个解锁哪个），不需要额外存储。
点奖杯有弹跳 + 撒纸屑的小动画。

### 左侧栏（精简版 · 一屏放下）
- **题单切换器**：只摆当前题单一行，点开是二级菜单（题目清单 / 切换题单 / 新建 / 删除）
- **统计**：已完成 / 剩余题数，以及「已标记 N 题 · 还有 N 题可换」
- **刷题日历**（可翻月）：
  - 只把「计划区间内」的空白日子标红；区间外（开始前 / 结束后）是中性灰，不算空缺
  - 已做题按 1-2 / 3-4 / 5-7 / 8+ 四档深浅着色；暂停期间是斜纹灰
  - 「**提前日**」（原定那天的题已被提前做掉）标薄荷青 + `↑`，悬停看提前做掉的题数
  - **悬停某天直接看当天做了哪几道**
- **更多**（弹窗）：学习统计（连续天数 / 7 日均量 / 难度分布 / 本周进度 /
  单日完成最多纪录）、数据管理（导出 JSON / CSV）、
  重新开始（重新开始一轮 / 重置进度 / 恢复默认）

### 重置与重来
| 操作 | 清掉 | 保留 |
|------|------|------|
| **重置进度** | 完成记录、已展开的天、换题池 | 总题数、每天题数；起始日改回今天 |
| **恢复默认** | 上面全部 + 计划设置 | 回到初始化向导 |
| **重新开始一轮** | 当前轮进度 | **本轮记录归档进「往期轮次」**，可回看 |

都带二次确认，都能撤销，都**只影响当前题单**。

### 多题单
默认自带 LeetCode 100（100 题 / 17 个分类）。新建题单：粘贴力扣题单链接
（`https://leetcode.cn/problem-list/xxxxxx/`，分享题单和官方标签题单如
`problem-list/hash-table/` 都可以），自动拉取并按考点标签分组
（需联网；借系统自带的 Edge / Chrome 无头拉取，不需要安装任何依赖，
`/studyplan/` 学习计划链接暂不支持）。

|----|--------|
| 前端 | 原生 HTML / CSS / JavaScript，**无框架、无构建步骤**，改完刷新即生效 |
| 后端 | Python **标准库** `http.server` + `json`，无 Flask / 无 FastAPI |
| 数据 | 单个 JSON 文件，原子写入（tmp + `os.replace`）防损坏 |
| 样式 | CSS 自定义属性 + 玻璃拟态 + `@keyframes` + 内联 SVG 图标 |
| 背景 | AI 生成的插画（`assets/*.jpg`）+ CSS 雾气 / 雨丝 / 竹叶动画 |

一些实现细节：
- **撤销栈**：每次写操作前压一份 JSON 快照，最多 30 步
- **DOM 搬运**：侧栏面板的节点常驻隐藏容器 `#dock`，打开弹窗时搬进去、关闭时搬回来，
  渲染逻辑完全复用
- **自定义 tooltip**：不用浏览器原生 `title`（黑框太丑），事件委托统一处理
- **版本自检**：服务端下发 ui.html / app.js 的时间戳，页面发现不一致会自己刷新
- **静态白名单**：只放行 `ui.html`、`app.js` 和 `assets/` 下的图片，禁止目录遍历
